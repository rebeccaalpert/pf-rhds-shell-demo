# PF + RHDS shell demo
A minimal standalone layout example with:

* PatternFly v6 drawer (resizable pill panel)
* RHDS masthead and universal footer
* Site footer with Light / Dark / System theme switcher
* Single page with 48 placeholder cards (no routing, no real data)

## Prerequisites
Node.js 20+ (LTS recommended)
npm (comes with Node)

## To run
```
npm install
npm run dev
```

This was generated with Cursor off of the Hummingbird demo in order to show the CSS changes that were required for their usage of the PatternFly page and drawer.
